OMORI ReZig built for the fake R36S (GA36-MB, Allwinner A23): 32-bit ARM, Cortex-A7, Mali-400.

Extract into `ports/` on the HOME partition so `ports/omori/run.sh` exists, put your own OMORI
Android APK (or a PC `www/` plus its `Launch_OMORI.bat`) into `ports/omori/original/`, then open
**OMORI** from the Ports menu. The first start prepares the game and takes a while.

No game data is included.

engine code is available under **MPL 2.0**. The game and its assets belong to their respective
